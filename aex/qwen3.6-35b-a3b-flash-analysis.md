## DDR vs Flash 分配方案

### 分配原则

```
┌──────────────────────────────────────────────────────────────┐
│                     DDR (常驻)                                │
│                                                              │
│  ┌──────────────────────────────────────────┐                │
│  │  Embedding + Output (~485 MB Q4_0)       │ ← 每个 token  │
│  ├──────────────────────────────────────────┤   都必须用     │
│  │  Full Attention Q/K/V/O (10层, ~90 MB)   │                │
│  ├──────────────────────────────────────────┤                │
│  │  Linear Attention 权重 (30层, ~309 MB)   │                │
│  ├──────────────────────────────────────────┤                │
│  │  共享 Expert FFN (40层, ~60 MB)          │ ← 每个 token  │
│  ├──────────────────────────────────────────┤   都激活       │
│  │  Router 权重 (40层, ~10 MB)              │ ← 决定选哪些  │
│  ├──────────────────────────────────────────┤   expert       │
│  │  All Norms (~1 MB)                       │                │
│  ├──────────────────────────────────────────┤                │
│  │  KV Cache (仅 10 层全注意力, 见下文)      │                │
│  ├──────────────────────────────────────────┤                │
│  │  Expert 缓存窗口 (滑动窗口)              │ ← Phase 3     │
│  └──────────────────────────────────────────┘                │
│                                                              │
│  DDR 常驻: ~955 MB + KV Cache + Expert 缓存                 │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                     Flash (按需加载)                          │
│                                                              │
│  ┌──────────────────────────────────────────┐                │
│  │  路由 Expert FFN (256 expert × 40 层)    │                │
│  │  ffn_gate_exps × 40 层                   │                │
│  │  ffn_up_exps × 40 层                     │ ← 总计         │
```

## KV Cache 分析 — 线性注意力的巨大优势

Qwen3.6-35B-A3B 的混合注意力结构对 Flash Inference 极其有利：

| 注意力类型 | 层数 | KV Cache 特性 | 每层每 token |
|-----------|------|-------------|-------------|
| **Full Attention** | 10 层 | 标准 KV Cache, O(n) 增长 | 2 × 2KV_heads × 256 × 2B = 2 KB |
| **Linear Attention** | 30 层 | 固定大小状态, O(1) | ~262 KB 固定 (不随 context 增长!) |

### KV Cache 大小对比

| Context 长度 | Qwen3-30B-A3B (48 层全注意力) | Qwen3.6-35B-A3B (10 层全注意力) | 节省 |
|-------------|------------------------------|-------------------------------|------|
| 2K tokens | 192 MB | 44 MB | **77%** |
| 4K tokens | 384 MB | 84 MB | **78%** |
| 8K tokens | 768 MB | 164 MB | **79%** |
| 32K tokens | 3,072 MB | 644 MB | **79%** |

> 线性注意力的固定状态开销: 30 层 × 16 × 128 × 128 × 4B ≈ **~30 MB** (一次性，不随 context 增长)

## 每 Token 的 Flash I/O 分析

### 单 token 推理流程

```
1. [DDR] Embedding lookup
2. 对每层:
   a. [DDR] Attention 计算 (全注意力或线性注意力)
   b. [DDR] Router 计算 (ffn_gate_inp @ cur → 选出 top-8 expert)
   c. [DDR] 共享 Expert FFN 计算
   d. [Flash → DDR] 加载 8 个路由 expert 的 gate/up/down 权重
   e. [DDR] 路由 Expert FFN 计算
   f. 残差连接
3. [DDR] Output projection
```

### 每 Token 从 Flash 读取的数据量

单个路由 expert 的权重大小:
- gate: 2048 × 512 × bytes_per_param
- up: 2048 × 512 × bytes_per_param
- down: 512 × 2048 × bytes_per_param
- **单个 expert 总参数: 3,145,728**

| 量化 | 单 expert | 8 expert/层 | 40 层/Token | 捆绑后/Token |
|------|-----------|-----------|------------|-------------|
| FP16 | 6.0 MB | 48.0 MB | **1,920 MB** | 853 ms @2.25GB/s |
| Q8_0 | 3.0 MB | 24.0 MB | **960 MB** | 427 ms |
| Q4_0 | 1.5 MB | 12.0 MB | **480 MB** | 213 ms |

### 滑动窗口 I/O 优化

| 窗口 W | Expert 重叠率 | 增量/Token (Q4_0) | Flash 读取延迟 @2.25GB/s |
|--------|-------------|-------------------|-------------------------|
| 0 | 0% | 480 MB | 213 ms |
| 4 | ~80% | 96 MB | 43 ms |
| 8 | ~85% | 72 MB | 32 ms |
| 16 | ~90% | 48 MB | 21 ms |
| 32 | ~93% | 34 MB | 15 ms |

### 行-列捆绑优化

每个 expert 的 gate+up+down 作为一个连续块 (Q4_0):

| 方式 | 块大小 | Flash 吞吐 | 8 expert/层延迟 |
|------|--------|-----------|----------------|
| 非捆绑 | 0.5 MB | ~1.25 GB/s | 9.6 ms |
| 捆绑 | 1.5 MB | ~2.25 GB/s | 5.3 ms |

## 总结

Qwen3.6-35B-A3B 比 Qwen3-30B-A3B **更适合** Flash Inference：

1. **DDR 常驻仅 ~460 MB (Q4_0)** — 比 Qwen3 少 38%
2. **KV Cache 极小** — 线性注意力 (30 层) 不增长 KV Cache，仅 10 层全注意力需要
3. **Expert 更稀疏** — 256 选 8 (3.1%) vs 128 选 8 (6.25%)，Flash 读取更少
4. **单 expert 更小** — 1.5 MB vs 2.25 MB，适合 Flash 随机读取
5. **MoE 天然零精度损失** — 路由器精确选择，无需近似
6. **共享 Expert** — 40 层共享 expert 仅 60 MB，对 DDR 压力小
7. **最低 ~1.5 GB DDR 即可运行** — 适合移动/嵌入式设备
